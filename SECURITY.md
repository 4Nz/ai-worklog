# Security Policy

## Supported Versions

Security fixes are provided for the latest published release.

## Reporting A Vulnerability

Do not open a public issue for an unpatched vulnerability. Report it through a
[GitHub private security advisory](https://github.com/4Nz/ai-worklog/security/advisories/new).

Include the affected version, installation method, impact, and a minimal
sanitized reproduction. Remove credentials, real Session IDs, Obsidian Vault
paths, project paths, repository secrets, and dossier contents.

The project will acknowledge a valid report, investigate it, and coordinate
disclosure through the advisory. No fixed response time is promised for this
maintainer-run public preview.

## Sensitive Data

AI Worklog dossiers can contain local paths, repository URLs, Agent identifiers,
Session IDs, resume commands, and work summaries. Users are responsible for
Vault permissions and synchronization settings. Plugin uninstall does not delete
archived data.
